# keyword-clusterer

*Cluster: Keywords & Links . Part of the 17 SEO Skills set by Vicky Lalwani, Digital Marketing Director.*

## Purpose

Turn a flat list of keywords or queries into intent-based topic clusters, each mapped to one page, so content is organized around topics rather than scattered single keywords.

## When to use

- The user has a keyword list or GSC export and needs structure
- Planning a content hub or pillar-cluster architecture
- Deciding which keywords belong on which page
- Before writing content, to group related terms onto single pages

## Inputs required

- A keyword list, or GSC queries, or a seed topic to expand (required)
- Optional: the existing pages, so clusters can be mapped to current URLs
- Optional: the site's vertical, to inform intent classification

## Step-by-step instructions

1. Gather the keywords (from the pasted list, GSC queries, or by expanding a seed topic).
2. Classify each keyword by search intent: informational, commercial investigation, transactional, navigational.
3. Group keywords that share the same topic AND the same intent into clusters. Keywords with the same topic but different intent go to separate clusters (and separate pages).
4. Name each cluster by its core topic and assign the single best primary keyword plus the supporting/secondary keywords.
5. Map each cluster to a target page: an existing URL if one fits, or 'new page needed' if not.
6. Flag overlaps: clusters that map to the same existing page, or two clusters close enough to risk cannibalization. Recommend merging or differentiating.

## Output format

A cluster table: Cluster name | Primary keyword | Secondary keywords | Intent | Target page (existing URL or 'new') | Notes. Plus flagged overlaps with a merge/differentiate recommendation.

## Quality checklist

- [ ] Every keyword is classified by intent before clustering
- [ ] Clusters group same topic AND same intent (not just same words)
- [ ] Each cluster has one primary keyword and a clear target page
- [ ] Same-topic-different-intent keywords are split into separate clusters
- [ ] Cannibalization risks (two clusters, one page) are flagged

## Optimization notes

Intent is the dividing line. 'Running shoes' (transactional) and 'how to choose running shoes' (informational) are the same topic but belong on different pages with different clusters. Cluster by intent first, topic second. One cluster equals one page - if two clusters want the same page, one of them needs its own.
