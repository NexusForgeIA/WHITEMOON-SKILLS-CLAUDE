# skills-seo

**17 free Claude Skills for SEO.** Drag the folder into Claude, connect Google Search Console (and Semrush for the Semrush skills), and ask. No setup, no API keys, no code.

Built by **Vicky Lalwani**, Digital Marketing Director.

---

## How to use

1. **Drop the folder into Claude.** Open a Claude Project and upload this `skills-seo` folder into the Project knowledge. Claude now has all 17 skills available.
2. **Connect your data.** Add the Google Search Console connector (a few skills read your live GSC data). For the Semrush skills, connect Semrush the same way.
3. **Tell it what you need.** Name the skill and your page or site. Claude reads that skill's instructions, then does the work and hands you the output.

The universal pattern:

```
Use the [skill-name] skill on [my page URL / my site / my GSC data].
Target keyword: [if relevant]
What I'm trying to improve: [clicks / rankings / indexing]
Read the skill, then give me the output and the actions ranked by impact.
```

## The 17 skills

### On-page & content
| Skill | What it does |
|---|---|
| `meta-optimizer` | Rewrites titles and meta descriptions that earn the click |
| `content-gap` | Compares your page to the top 10 and tells you what's missing |
| `internal-linker` | Finds orphan pages, suggests links from existing content |
| `schema-generator` | Builds valid JSON-LD schema for any page type |
| `cannibalization-finder` | Spots pages fighting over the same keyword |
| `ctr-booster` | Finds high-impression, low-CTR pages and fixes them |

### Google Search Console
| Skill | What it does |
|---|---|
| `gsc-auditor` | Pulls GSC data, surfaces prioritized quick wins |
| `gsc-errors` | Finds and fixes indexing and coverage errors |

### Semrush
| Skill | What it does |
|---|---|
| `semrush-auditor` | Audits your Semrush site issues in one pass |
| `semrush-errors` | Turns Semrush flags into ranked, executable fixes |

### Technical SEO
| Skill | What it does |
|---|---|
| `technical-auditor` | Crawls and detects technical SEO issues |
| `technical-errors` | Turns technical findings into ranked fixes + dev brief |
| `robots-checker` | Checks robots.txt and indexing directives |
| `sitemap-validator` | Validates your XML sitemaps |

### Keywords & links
| Skill | What it does |
|---|---|
| `keyword-clusterer` | Groups queries into intent-based topic clusters |
| `backlink-analyzer` | Scores your link profile, flags toxic links |
| `github-seo-optimizer` | Optimizes GitHub repos for discoverability |

## The weekly routine

You won't run all 17 every week. Run these 5:

- **Monday** — `gsc-auditor` (set your focus for the week)
- **Tuesday** — `ctr-booster` (then feed winners to `meta-optimizer`)
- **Wednesday** — `technical-errors` (batch the dev fixes)
- **Thursday** — `content-gap` (pick one page stuck on page 2)
- **Friday** — `gsc-errors` (end the week with a clean index)

The other 12 are on-demand: `schema-generator` on launch, `cannibalization-finder` when rankings get weird, `backlink-analyzer` monthly.
